# لُمعة · موقع عيادة عناية بالبشرة

موقع كامل بلغتين لعيادة عناية بالبشرة **وهمية** اسمها «لُمعة» (Lumaa)، صُمّم لمعرض الأعمال، ويصلح قالبًا لعيادات حقيقية بتعديل ملفين فقط.

**الموقع المباشر:** [lumaa-clinic.vercel.app](https://lumaa-clinic.vercel.app)

- عربي (الافتراضي) وإنجليزي، والاتجاه والخطوط يتغيران مع اللغة، والاختيار يُحفظ في المتصفح
- وضع داكن تلقائي حسب جهاز الزائر، مع زر يثبّت الوضع يدويًا
- شاشة تحميل قصيرة يلمع فيها الشعار، ثم العنوان يظهر كلمةً كلمة مع لمعة ذهبية على «تلمع»
- لوحة «تحليل البشرة»: صورة وجه مولّدة بالذكاء الاصطناعي (عبر Canva، لا تعود لشخص حقيقي) في `public/face.webp`، وفوقها طبقة مرسومة بـ canvas تتبدل بزر «قبل/بعد» (رؤوس سوداء ونتوءات واحمرار، أو صفاء ولمعان)، وعدسة تكبير تتبع الماوس وتتجول وحدها على الجوال
- محلّل بشرة مصغّر: 3 أسئلة تقترح الخدمة المناسبة وتختارها في نموذج الحجز
- بطاقات خدمات بصور، والضغط على أي بطاقة يفتح نافذة تفاصيل (ماذا تشمل الجلسة، لمن تناسب، السعر) مع زر حجز مباشر
- بطاقات تميل ثلاثي الأبعاد مع بقعة ضوء، وشريط آراء يتحرك ويُسحب، وخط زمني يُرسم مع التمرير
- نموذج حجز بثلاث مراحل (الخدمة ← الموعد ← بياناتك) مع مؤشر تقدم وبطاقة «ملخص حجزك» تتحدث مباشرة، وتقويم مرسوم (الجمعة والأيام الماضية معطّلة)، ثم يفتح واتساب برسالة جاهزة
- شريط مقارنة «قبل وبعد» مرسوم بـ canvas، يعمل بالماوس واللمس ولوحة المفاتيح
- يبدأ تصميمه من الجوال، ولا يظهر فيه تمرير أفقي على عرض 360 بكسل
- يحترم إعداد «تقليل الحركة»، ويعمل بلوحة المفاتيح بإطار تركيز واضح، وفحص axe لم يجد أي مخالفة

> موقع تجريبي لعيادة غير موجودة. الأسماء والأرقام والآراء كلها خيالية، ورقم واتساب وهمي.

## التشغيل على جهازك

تحتاج **Node.js 20** أو أحدث.

```bash
npm install
```

```bash
npm run dev
```

ثم افتح الرابط الذي يظهر (عادة `http://localhost:5173`). أي تعديل تحفظه يظهر في المتصفح مباشرة.

أوامر أخرى:

| الأمر | ماذا يفعل |
| --- | --- |
| `npm run build` | يتحقق من TypeScript ثم يبني نسخة النشر في مجلد `dist` |
| `npm run preview` | يعرض نسخة `dist` كما ستظهر بعد النشر |
| `npm run lint` | يفحص الكود بحثًا عن أخطاء شائعة |

### النصوص والأسعار: `src/content/site.ts`

كل نص مكتوب بلغتين في المكان نفسه:

```ts
name: { ar: 'هيدرافيشل', en: 'HydraFacial' },
priceFrom: 450, // رقم فقط، والموقع يكتبه «450 ريال» أو «SAR 450»
```

- **تغيير سعر:** ابحث عن اسم الخدمة وغيّر رقم `priceFrom`.
- **إضافة خدمة:** انسخ خدمة كاملة داخل `services.items`، وأعطها `id` جديدًا بالإنجليزية بدون مسافات. تظهر البطاقة وخيارها في نموذج الحجز تلقائيًا.
- **صورة الخدمة:** ضع صورة بنسبة 4:3 (يكفي 960×720) في `public/services` بصيغتين `.webp` و`.jpg` بالاسم نفسه، واكتب مسارها في `image` بدون الامتداد (مثل `/services/hydrafacial`)، ووصفها في `imageAlt`. الصور الحالية مولّدة بالذكاء الاصطناعي عبر Canva ولا تعود لأشخاص حقيقيين.
- **تفاصيل الخدمة:** `includes` نقاط «ماذا تشمل الجلسة»، و`idealFor` لمن تناسب. تظهران في نافذة التفاصيل.
- **رقم واتساب:** عدّل `brand.whatsappNumber` بالصيغة الدولية بدون + (مثل `966512345678`)، و`brand.phoneDisplay` للشكل الذي يراه الزائر.
- **أوقات الحجز وأيام الإغلاق:** `booking.timeSlots` بصيغة 24 ساعة (`'16:00'`)، و`booking.closedDays` حيث 0 = الأحد و5 = الجمعة.
- **عنوان الصفحة ووصفها لمحركات البحث:** `meta.title` و`meta.description`. تُكتب في `index.html` تلقائيًا عند التشغيل والبناء.
- **محلّل البشرة:** الأسئلة في `quiz.questions`. كل خيار يحمل `scores` بنقاط لكل خدمة (بمعرّفها `id`)، والخدمة ذات المجموع الأعلى هي المقترحة. رقم سالب يستبعد خدمة.
- **لماذا لُمعة:** البطاقات في `why.items`. ضع `size: 'large'` لبطاقة بعرض عمودين، و`stat` لرقم كبير يعدّ عند ظهوره.

إذا أخطأت في اسم حقل أو نسيت ترجمة، يظهر خط أحمر في المحرر ويتوقف `npm run build` برسالة توضح المكان، فلا يصل الخطأ إلى الموقع.

### الألوان والخطوط: `src/styles/theme.css`

كل لون مكتوب مرة واحدة بقيمتين (الفاتح ثم الداكن)، وبجانبه تعليق يشرح استخدامه:

```css
--canvas: light-dark(#f8f1ec, #1b1310); /* خلفية الصفحة */
--ink: light-dark(#2f221c, #f4e9e0);    /* النص الأساسي */
--gold: light-dark(#c8a26b, #c9a46c);   /* ذهبي للزخارف */
```

- الوضع يتبع جهاز الزائر تلقائيًا، وزر القمر/الشمس في الشريط العلوي يثبّته ويحفظه في المتصفح.
- **تغيير الخطوط:** عدّل `--brand-font-heading` و`--brand-font-body` (العربية في `:root`، والإنجليزية في `html[lang='en']`)، ثم حدّث رابط Google Fonts في `index.html`.
- لا تضع لونًا فاتحًا للنص الصغير: الذهبي `--gold` للزخارف فقط، و`--gold-deep` هو الذهبي الآمن للنص.

### التحقق من رقم الجوال

النموذج يقبل الأرقام السعودية (`05xxxxxxxx` أو `+9665…`)، ويقبل الأرقام العربية ٠٥ أيضًا. لعيادة في بلد آخر عدّل `PHONE_PATTERN` في `src/lib/validation.ts` ونص الخطأ `phoneInvalid` في `site.ts`.

## النشر على Vercel

> هذا المشروع مربوط بمستودع [github.com/7amzabd/lumaa-clinic](https://github.com/7amzabd/lumaa-clinic):
> أي `git push` إلى الفرع `main` يُنشر تلقائيًا على الموقع المباشر خلال دقيقة تقريبًا.

### الطريقة الأولى: من GitHub (الأسهل)

1. ارفع المشروع إلى مستودع على GitHub.
2. ادخل [vercel.com](https://vercel.com)، ثم **Add New → Project**، واختر المستودع.
3. سيتعرّف Vercel على Vite تلقائيًا (أمر البناء `npm run build` ومجلد النتيجة `dist`)، فاضغط **Deploy**.
4. بعد النشر انسخ رابط موقعك وضعه في `meta.siteUrl` داخل `site.ts`، ثم ارفع التعديل. أي `push` لاحق يُنشر تلقائيًا.

### الطريقة الثانية: من سطر الأوامر

```bash
npm install -g vercel
```

```bash
vercel
```

```bash
vercel --prod
```

لا يحتاج المشروع ملف `vercel.json` لأنه صفحة واحدة ثابتة.

## قائمة التحويل لعيادة حقيقية

1. `site.ts`: الاسم، النصوص، الأسعار، رقم واتساب، العنوان، روابط الحسابات في `footer.socials`.
2. `site.ts`: اجعل `meta.noIndex` = `false` ليظهر الموقع في محركات البحث، وضع الرابط الحقيقي في `meta.siteUrl`.
3. `site.ts`: اجعل نص `footer.demoNote` فارغًا `''` فيختفي سطر «موقع تجريبي».
4. `theme.css`: ألوان العيادة وخطوطها، ثم لون `theme-color` في `index.html`.
5. مجلد `public`: استبدل `og-image.jpg` (‏1200×630) و`favicon.svg` و`apple-touch-icon.png` (‏180×180).
6. لا تنشر صورًا أو بيانات عميل قبل موافقته المكتوبة.

```

├─ index.html                 قالب الصفحة: الخطوط، الأيقونات، بيانات المشاركة

├─ public/                    favicon.svg · apple-touch-icon.png · og-image.jpg
└─ src/
   ├─ main.tsx                نقطة البداية: مزوّد اللغة، مزوّد الحجز، إعدادات motion
   ├─ App.tsx                 ترتيب الأقسام
   ├─ content/
   │  ├─ site.ts              ★ كل المحتوى بلغتين
   │  └─ types.ts             شكل البيانات (يكشف أخطاء التعديل)
   ├─ styles/
   │  ├─ theme.css            ★ الألوان والخطوط
   │  └─ global.css           ربط الألوان بـ Tailwind وأنماط مشتركة
   ├─ i18n/                   اللغة والاتجاه وحفظ الاختيار
   ├─ theme/                  الوضع الفاتح/الداكن وزر تثبيته
   ├─ state/                  الخدمة المختارة بين البطاقات ونموذج الحجز، وانتهاء شاشة التحميل
   ├─ hooks/                  مراقبة القسم الظاهر على الشاشة
   ├─ lib/                    التنسيق، التحقق، رابط واتساب، رسم البشرة، مؤثرات قبل/بعد فوق الصورة، اقتراح الخدمة، حركة الأرقام
   └─ components/
      ├─ layout/              الشريط العلوي، قائمة الجوال، شريط الحجز السفلي، التذييل
      ├─ sections/            أقسام الصفحة العشرة (منها محلّل البشرة و«لماذا لُمعة»)
      ├─ booking/             نموذج الحجز، التقويم، ورسالة التأكيد
      └─ ui/                  عناصر مشتركة (زر، أيقونات، لمعة، لوحة الصورة والعدسة، بطاقة مائلة، شريط متحرك…)
```
